# Asistencia Barra

## Objetivo

Crear una aplicación móvil para Android e iPhone para controlar la asistencia del personal de Barra Cueros.

## Tecnologías

- React Native con Expo
- Supabase
- TypeScript

## Reglas

- La aplicación debe funcionar en Android y iPhone.
- Debe ser rápida y muy sencilla.
- Botones grandes.
- Todo en español.

## Funciones

- Login
- Marcar Entrada
- Inicio de Almuerzo
- Fin de Almuerzo
- Marcar Salida

## GPS

Solo permitir marcar asistencia cuando el trabajador esté dentro de un radio de 50 metros de la tienda.

## Administrador

- Ver asistencias
- Ver trabajadores
- Exportar a Excel
- Ver tardanzas

## Diseño

Colores sobrios.
Interfaz simple.
Botones grandes.
Pensada para personas que no saben usar tecnología.
